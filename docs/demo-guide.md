# 5–8 Minute Video Demo Guide

## 1. Introduction — 20 seconds

“This is PhishAware, my CodeAlpha Cyber Security Internship Task 2 project. It is a browser-based phishing-awareness training module built with HTML, CSS, and vanilla JavaScript.”

## 2. Objective and homepage — 30 seconds

Show the learning path, estimated time, responsive interface, and device-local progress. Explain that the platform is educational and has no backend or credential collection.

## 3. Fundamentals and types — 35 seconds

Show the attack lifecycle. Expand one phishing-type card and mention that email, SMS, voice, social media, and QR codes can all carry phishing.

## 4. Email red flags — 40 seconds

Select **Show red flags**. Point out the sender domain, urgent request, link destination, and credential request. State that polished grammar, logos, and HTTPS are not proof of legitimacy.

## 5. Spot the Phish — 35 seconds

Answer one message. Read the immediate explanation and emphasize evidence-based reasoning.

## 6. Fake website and URL lab — 55 seconds

Show the visual-only sign-in simulation. Explain that there are no input fields. In URL Detective, identify the registrable domain and answer one exercise.

## 7. Social engineering scenario — 40 seconds

Open a tactic card, then choose the independent verification option in one scenario. Explain how this interrupts urgency or authority pressure.

## 8. Best practices and post-click response — 40 seconds

Briefly cover links, sign-ins, account protection, reporting, password change through the official service, session review, and MFA.

## 9. Final quiz — 50 seconds

Answer several questions, then use a prepared completed run or quickly finish the quiz. Show the score, neutral learning label, explanations, and recommended review modules.

## 10. Dashboard and repository — 40 seconds

Show module completion, challenge accuracy, quiz result, badges, and reset control. Then show the repository structure and documentation files.

## 11. Closing — 20 seconds

“The project fulfills the CodeAlpha requirement with structured training, phishing-email and fake-site recognition, social-engineering education, prevention guidance, real-world patterns, interactive exercises, and a final quiz.”
