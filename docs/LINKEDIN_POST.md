# LinkedIn Post

I have completed **Task 2 — Phishing Awareness Training** for the **CodeAlpha Cyber Security Internship**.

My project, **PhishAware**, is an interactive browser-based training module that helps users understand phishing and make safer decisions when handling suspicious messages, links, websites, and social-engineering requests.

The project includes:

- Structured lessons covering phishing types, warning signs, social-engineering tactics, prevention, and incident response
- A fictional email red-flag demonstration
- Safe, non-operational fake website training
- Message, URL, and social-engineering decision exercises with immediate explanations
- A 12-question final quiz with scoring and answer review
- Device-local progress tracking and an achievement dashboard

I built the application with HTML5, CSS3, vanilla JavaScript, and browser localStorage. The project has no backend and does not collect credentials or personal information. All simulations use fictional organizations and safe example-style domains.

This task helped me improve my understanding of phishing analysis, URL structure, social engineering, defensive incident response, accessible interface design, and browser-based state management.
