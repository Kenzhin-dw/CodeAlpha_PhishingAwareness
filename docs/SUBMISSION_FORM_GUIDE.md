# CodeAlpha Submission Form Guide

This project represents:

- **Task:** Task 2
- **Project:** PhishAware — Interactive Phishing Awareness Training

## LinkedIn Video Explanation Post Link — Task 2

Paste the URL of the **published LinkedIn post that contains your technical explanation video**.

Correct type of link:

```text
https://www.linkedin.com/posts/...
```

Do not paste:

- your LinkedIn profile URL;
- a local video file path;
- an unpublished draft;
- the GitHub repository URL.

## GitHub Repository Link — Task 2

Paste the URL of the **public or otherwise accessible GitHub repository for PhishAware**.

Correct format:

```text
https://github.com/<username>/CodeAlpha_PhishingAwareness
```

Do not paste:

- your GitHub profile URL;
- a link to one source file;
- a private preview deployment URL;
- the LinkedIn post URL.

## Final verification

Before submitting the form:

1. Open a private or incognito browser window.
2. Open the GitHub repository URL and confirm that the README and project files are visible.
3. Open the LinkedIn post URL and confirm that the post and video are visible.
4. Confirm that both URLs correspond to **Task 2**.
5. Paste each URL into its matching field.
6. Review the complete form before selecting Submit.
