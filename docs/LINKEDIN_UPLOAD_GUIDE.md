# Manual LinkedIn Video Upload Guide

No LinkedIn account action has been performed automatically. Complete these steps manually after the GitHub repository is public and the video has been reviewed.

## Before uploading

1. Watch the complete video once.
2. Confirm that the audio is understandable.
3. Confirm that the screen does not show passwords, tokens, email addresses, private repository URLs, notifications, personal bookmarks, or unrelated files.
4. Copy the final public GitHub repository URL.
5. Open `docs/LINKEDIN_POST.md` and replace:

   ```text
   <PASTE_GITHUB_LINK_HERE>
   ```

   with the real repository URL.

## Publish the video post

1. Manually open LinkedIn and sign in.
2. On the home page, choose **Start a post**.
3. Select the media or video option.
4. Choose the final recorded PhishAware explanation video.
5. Wait for LinkedIn to finish processing the video.
6. Paste the prepared caption from `docs/LINKEDIN_POST.md`.
7. Check that the GitHub URL points to the specific public repository, not to your GitHub profile.
8. Review the caption, video thumbnail, hashtags, and visibility.
9. Publish the post manually.

## Copy the LinkedIn post URL

1. Open the published post itself.
2. Use the post menu and choose **Copy link to post**, or copy the URL while the individual post is open.
3. Open a private or incognito browser window and test the URL.
4. Confirm that it opens the video post without requiring access to a private audience.

The URL needed by CodeAlpha is the **published LinkedIn post URL containing the video**. Do not submit your LinkedIn profile URL.
